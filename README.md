## Overview

Blue Cat Destructor is a modular distortion processor with six independent distortion stages, pre and post EQ, compression, noise gate, and an impulse response convolution loader for cab simulation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Blue Cat Destructor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Six Distortion Stages** | Stack up to six distortion algorithms in any order |
| **Pre/Post EQ** | Four-band EQ before and after the distortion chain |
| **IR Loader** | Convolution impulse response loader for guitar cabinet simulation |
| **Gate and Comp** | Integrated noise gate and compressor for recording-ready tone |
